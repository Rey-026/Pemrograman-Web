# 🌐 Pemrograman Web Repository

Repositori ini berisi kumpulan kode, latihan, dan proyek pengembangan web (HTML, CSS, dan JavaScript) yang saya kembangkan.

## 🚀 Live Demo
Kamu dapat melihat hasil web yang di-deploy secara *live* melalui tautan berikut:
👉 [https://rey-026.github.io/Pemrograman-Web/](https://rey-026.github.io/Pemrograman-Web/)

---

## 📂 Struktur Direktori
* `index.html` - Halaman utama (*entry point*) situs web.
* `CSS/` - Berisi file penata gaya (*stylesheet*) untuk desain antarmuka.
* `JS/` - Berisi file logika dan interaksi berbasis JavaScript.

---

## 🛠️ Teknologi yang Digunakan
* **HTML5** - Struktur dasar halaman web.
* **CSS3** - Desain dan tata letak (*styling*).
* **JavaScript** - Interaktivitas dan fungsionalitas sisi klien.
* **GitHub Pages** - Layanan hosting untuk publikasi web statis.
